# vip2cars-entrega

Bienvenido al repositorio del proyecto **vip2cars-entrega**.

## ¿Cómo puedo colocar mi código aquí?

Sigue estos pasos para subir tu código a este repositorio:

### Opción 1 – Usando Git desde la terminal

1. **Clona el repositorio** en tu computadora:
   ```bash
   git clone https://github.com/pedroSor/vip2cars-entrega.git
   cd vip2cars-entrega
   ```

2. **Agrega tus archivos** al directorio clonado (copia o crea tus archivos de código aquí).

3. **Registra los cambios** con Git:
   ```bash
   git add .
   git commit -m "Agrego mi código inicial"
   ```

4. **Sube los cambios** a GitHub:
   ```bash
   git push origin main
   ```

### Opción 2 – Subiendo archivos directamente en GitHub

1. Abre el repositorio en GitHub: [https://github.com/pedroSor/vip2cars-entrega](https://github.com/pedroSor/vip2cars-entrega)
2. Haz clic en el botón **"Add file"** → **"Upload files"**.
3. Arrastra tus archivos o haz clic en **"choose your files"** para seleccionarlos.
4. Escribe un mensaje de confirmación (commit message) y haz clic en **"Commit changes"**.

### Opción 3 – Editando archivos directamente en GitHub

1. Haz clic en el ícono de lápiz ✏️ junto a cualquier archivo existente para editarlo en el navegador.
2. Haz clic en **"Commit changes"** cuando termines.
